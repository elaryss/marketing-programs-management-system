System anatomy

How the system fits together

A system where historical program data feeds current planning and decisions, and a request for a new report runs itself end-to-end. The real closed loop: a report is requested, built by an agent, reviewed by a second agent against the original request, and delivered — with a human able to step in at any point.

Data layer
Supabase Postgres. Toolkit line items with full lifecycle — specs, selected vendor pricing, and order snapshots across original / revised / final stages. Analytical views power the dashboards.
Agentic layer
Six AI-powered agents. A chat analyst that answers questions about data; a report-intake agent; a report-builder agent; a review agent that grades each report against the original request; an MOQ recommender (Python + AI); and a weekly chat-themes summarizer.
Pipelines
Supabase webhook → auto-build. A new report request fires the builder agent. A review agent then scores it; on a passing grade the approved report is emailed to the user.
